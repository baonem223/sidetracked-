PROJECT HIGHLIGHTS

01 / CAMPAIGN STRATEGY

Our team developed a digital advertising campaign for Sidetrack Skate Shop to increase brand awareness and attract potential customers. We identified our target audience, established campaign goals, and explored how display advertising can reach customers interested in skateboarding, streetwear, and creative culture.

02 / CREATIVE AD DESIGN

We designed four display advertisements in different sizes to accommodate various website placements. Each advertisement uses colorful graphics, consistent branding, and a clear "Shop Now" message.

03 / WEBSITE DEVELOPMENT

We created a three-page website using HTML, CSS, and JavaScript and published it through GitHub Pages. All four advertisements connect to the landing page for a consistent user experience.
